稳态  ·  时域  ·  同一组半导体方程

两个引擎，同一套器件物理

SCAPS-1D 与 SolarLab 对同一个薄膜叠层求解同一套方程组，即泊松方程与载流子连续性方程的耦合形式。两者的差别集中在三处选择上，其余分歧都由它们派生：哪些量作为未知量、时间是否算作一个坐标、光以什么方式进入薄膜。本页并列这三处选择，逐项说明各自的代价与所得。

本页是 SolarLab 求解器讲解页的配套材料。琥珀色一侧的内容全部出自 SCAPS 手册（v3.3.03，2016 年 2 月）和 Burgelman 课题组已发表的算法论文，青色一侧全部出自 SolarLab 源码树。

维度 · 未知量

求解器以什么为未知量

两套程序离散同一组方程：泊松方程一条，载流子连续性方程两条。第一处分歧出现在因变量的选取上：SCAPS 取准费米能级，SolarLab 取载流子浓度，并额外输运第三种粒子。

SCAPS-1D

(ψ, EFn, EFp)：稳态

— 泊松方程 —
−∂/∂x( ε ∂ψ/∂x ) = q( p − n + ND+ − NA− + ρdef )

— 连续性方程（∂/∂t = 0）—
∂Jn/∂x = q( Un − G )
∂Jp/∂x = −q( Up − G )

— 本构关系 —
Jn = μn n ∂EFn/∂x    Jp = μp p ∂EFp/∂x
  • 电流写成准费米能级的梯度，有效态密度与能带偏移已包含在变量定义之中。
  • 全程采用玻尔兹曼统计，费米-狄拉克统计与带隙收窄均未实现。
  • 缺陷电荷 ρdef 的模型相当丰富：单价、二价与多价缺陷，两性缺陷，单能级 / 均匀 / 高斯 / 带尾分布，以及需另设占据率迭代求解的亚稳组态。
  • 时间仅出现在一次独立的小信号线性化中：Y = δJ/δuext = jωC + G。

SolarLab

每个节点 y = (n, p, P)：时间分辨

— 参与时间推进（线方法）—
∂n/∂t = (1/q) ∂Jn/∂x + G − R
∂p/∂t = −(1/q) ∂Jp/∂x + G − R
∂P/∂t = ∂/∂x[ DI( ∂P/∂x + (P/VT) ∂φ/∂x ) ]

— 直接求解，不作时间积分 —
−∂/∂x( ε ∂φ/∂x ) = q( p − n + P − NA + ND )
  • 状态量是载流子浓度；电势 φ 在每次右端项求值时由预先分解的三对角方程直接解出，不设内层泊松–牛顿迭代。
  • 第三种粒子为可动离子空位 P，在同一电场中漂移，遵循 Nernst–Planck 形式；第二种离子与空间位阻占据上限均为可选项。
  • SG 通量以 φ+χ 驱动电子，以 φ+χ+Eg 驱动空穴，SCAPS 中自动包含的有效态密度项在此必须显式折入（dos_band_potentials）；在对标器件上，该项合计 137 mV。
  • 费米-狄拉克统计可逐层开启；默认关闭为有意设定，与参照程序采用的玻尔兹曼统计一致。
差异 在纯稳态问题上，准费米能级的条件数更好：同一叠层若用浓度型牛顿迭代会停滞，SCAPS 仍能收敛。一旦要求 ∂/∂t ≠ 0，浓度就成为必需的状态量：离子输运、陷阱俘获与位移电流，描述的都是某个浓度随时间的变化。
维度 · 离散化

网格点放在哪里

两套程序都在能带弯曲处加密节点。差别有两处：SCAPS 在求解过程中重新生成网格，且每个界面坐标上放置两个节点；界面双节点在异质结处带来实质的物理差异。

SCAPS-1D

自适应网格，迭代之间重新生成

  • 体内网格稀疏，界面与接触处加密。
  • 每个界面坐标上有两个网格点，相邻两层各占一个；界面载流子浓度因而按两侧分别定义，是真实的平面量。
  • 网格可在每次迭代后重算，为可选项：相邻节点上 exp(qψ/kT)、exp(EFn/kT)、exp(EFp/kT)、R 与 G 的比值超过 fmax = 1.60（约 12 mV）则插入节点，低于 fmin = 1.05（约 1.2 mV）则删除节点。
  • 半导体层最多 7 层；每个电压点最多重构 10 次网格。

SolarLab

静态 tanh 加密多层网格

  • 各层节点数逐层指定，以 tanh 向每个界面加密；网格只构建一次，整个运行过程复用。
  • 每个界面只有一个节点，两层共用；能带偏移因此落在单个网格单元内，需要以热电子发射上限对 Scharfetter–Gummel 通量限幅。
  • 固定网格是 MaterialArrays 缓存与预分解泊松 LU 的前提：依赖几何的计算只执行一次，不必每次迭代重复。
  • 需要界面平面浓度时，由物理关系重构，而非依靠网格分辨：可用准稳态的 2×2 通量平衡（interface_plane_closure），也可在稳态牛顿迭代中显式引入界面平面态未知量。
差异 SCAPS 以每次迭代的额外开销换取稳健性，在陡峭带隙渐变与多价缺陷下获益。SolarLab 放弃自适应，换来可复用的缓存：一次扫描约 105 次右端项求值共用同一套几何数据。几何不变，而时间步成千上万，缓存的收益因此高于自适应。界面双节点是 SCAPS 网格在物理上更丰富的唯一一处，SolarLab 先后尝试五种表述，才补足这处差距。
维度 · 求解驱动

解是如何求得的

求解驱动这一层的分歧最深。SCAPS 是一个非线性方程组求解器，外层由延拓策略逐级推进。SolarLab 默认按刚性初值问题对器件做时间积分；直接求稳态的牛顿驱动为后续增补，用于定义可与 SCAPS 对照的物理量。

SCAPS-1D

Gummel 迭代 + Newton–Raphson 子步

— 延拓阶梯 —
起点（EF 平直，无电势降）
  ↓  暗平衡态，0 V
  ↓  短路，1 sun，0 V
  ↓  工作点
  ↓  第一个测量点 → 扫描
  • 外层为解耦的 Gummel 循环，每个方程内部再执行 Newton–Raphson 子步。
  • ψ、EFn、EFp 每次迭代的更新量限幅于 0.5 kT/q；更新量全部降至 0.001 kT 以下即判定收敛；迭代上限 1000 次。
  • 相邻两级相距过远时自动插入中间子步，是处理发散的常规手段。
  • 可选“过 Voc 即停”；单次扫描最多 201 个测量点。

SolarLab

线方法 + 隐式 Radau（另配稳态牛顿）

— 每个电压步 —
y(tk) → solve_ivp(Radau IIA, max_step 设上限)
  ↳ 失败时：稳定时间二分细分（≤ 10 次）
  ↳ 最后手段：改用 BDF 重试
y(tk+1) 将 n、p 连同离子分布一并传入下一步

— 可选的无离子稳态 —
阻尼对数空间牛顿求解 F(y) = 0，复用 LU 分解
  • Radau IIA（L 稳定，5 阶）吸收离子–载流子–电场耦合的刚性。之所以给步长设上限，是因为临近平带时雅可比矩阵趋于奇异，误差估计器会低估真实误差。
  • 稳态驱动与瞬态积分共用同一套装配好的右端项：一套物理，两个驱动。牛顿无法收敛处改由已验证的瞬态回退计算，结果均如实记录。
  • 偏压点之间的离子记忆并非后处理产物：上一步收敛的状态就是下一步的初始条件。
差异 稳态求解器回答器件在偏压 V 下如何工作，时域积分器回答电压以速率 r 变化过程中器件如何工作。钙钛矿属于两个答案存在可测差别的体系，实验测得的即为后者。
维度 · 边界条件

接触边界如何约束

SCAPS-1D

金属功函数，或反解得到的平带

  • 前后接触对多数载流子各取一个金属功函数 Φm。另一种选项是“平带”：SCAPS 在每个温度下反解 Φm，使能带保持平直；2014 年之后的版本改用包含深能级缺陷的总电荷中性条件求解。
  • 电子与空穴各有一个有限的表面复合速度，决定接触处的动力学，惯用默认值为 107 cm/s。
  • 隧穿进出接触为可选项；每个接触还可指定一份随波长变化的反射/透射滤光片文件。
  • 外部串联电阻与并联电阻在仿真之后施加：重新映射端电压，不进入输运问题本身；量子效率的计算同样不含这两项。

SolarLab

三种接触约定可选

  • 欧姆接触的狄利克雷钉扎（默认，IonMonger 约定）：边界载流子浓度钉在暗态掺杂平衡值，泊松方程以配置中给定的 Vbi 为参考。
  • 罗宾 / 选择性 / 肖特基：每一侧、每种载流子各取有限的 Sn、Sp，J = ±q·S·(浓度 − 浓度eq)；S → ∞ 回到欧姆接触，S = 0 为完全阻挡。
  • 平带金属接触，即 SCAPS 的约定：泊松边界取 compute_V_bi() 算出的功函数差，而不是配置中的固定输入值。
  • 已记录的限制：平带接触与稳态牛顿互不兼容（罗宾边界叠加陡峭的 Vbi，条件数恶化，牛顿迭代停滞）。SolarLab 将其记为引擎边界，未以补丁掩盖。
差异 两套程序在掺杂扫描上的表观分歧，最大的单一来源是接触约定：SolarLab 的 Vbi 边界随偏压与掺杂变化，在 ETL 掺杂扫描下的变化方式与 SCAPS 的固定金属功函数差异明显。SolarLab 现已实现两种约定，原先记作“趋势错误”的问题，现在归结为一处明确、可复现的边界条件差异。
维度 · 异质结

界面上发生了什么

两套程序都用热电子发射描述界面输运，界面复合都写成 SRH 型循环。差别在于复合速率能取到哪一处的载流子浓度。

SCAPS-1D

界面双节点上的热电子发射

  • 界面输运按热电子发射计算，热速度 vth 取相邻两层中较小的一个。每个界面上因此都有一个小的准费米能级台阶，能带偏移为零时也不例外。
  • 界面复合采用 Pauwels–Vanhoutte 理论，即 SRH 的一种推广：单一陷阱占据率同时平衡两侧的俘获。
  • 半经典隧穿有四条通道：带间、带内、能带 ↔ 界面缺陷、能带 ↔ 接触，均只在直流问题中生效，交流计算不予计入。

SolarLab

SG 通量取 TE 上限，另加平面浓度闭合

  • 界面上 |ΔEC| 或 |ΔEV| 超过 0.05 eV 时，Scharfetter–Gummel 通量限幅到 Richardson–Dushman 热电子发射极限；能带偏移落在单个网格单元上，不限幅会造成过量注入。
  • 界面 SRH 的 (vn, vp) 逐个界面指定。界面在网格上只占一个共用节点，平面浓度必须另行重建：或在每次右端项求值时解一个 2×2 隐式通量平衡，或在稳态 Newton 中把界面平面态列为显式未知量。
  • 隧穿只保留一条通道：静态的 Padovani–Stratton 热场发射增强因子 Γ ≥ 1，折入 Richardson 常数。增强因子刻意在构建阶段一次算定，不进入迭代，也就不会扰动 Newton 的收缩性。
差异 界面处理上 SCAPS 领先，记录中也照实写明。在平面浓度方案成立之前，基于体节点浓度的速率代数改写过三版，对照 SCAPS 的界面趋势全部被证伪。由此得到一条可复用的结论：浓度取自准费米能级已自洽的体节点时，任何密度乘积型速率式在该区间都无法体现陷阱能级的影响，只有界面平面浓度才反映这一依赖关系。
维度 · 光学

光如何变成 G(x)

SCAPS 的内置光学模型有意从简：非相干比尔-朗伯吸收，反射只允许发生在接触处，内部界面不反射。吸收系数由文件给出，或取自模型 α(λ) = (A + B/hν)·√(hν − Eg)。手册预期更精细的光学由外部 g(x) 文件提供。SolarLab 自行求解光学，并计入相干效应。

SCAPS-1D

非相干，单次通过

  • 整个叠层按比尔-朗伯吸收计算，α 取自模型或文件，α(λ,y) 可随组分渐变。
  • 反射/透射滤光片只能置于接触处；此外提供中性密度滤光片、截止滤光片、任一侧入射，以及一个光谱库（AM0、AM1.5D、AM1.5G、单色光）。
  • 没有干涉，没有内部界面反射，也没有背反射层驻波。手册对此有明确说明，并以导入 g(x) 作为替代途径。

SolarLab

相干传输矩阵法，光学闭环

  • Pettersson/Burkhard 传输矩阵覆盖整个叠层，只参与光学的衬底同样计入；配合 nreal/nambient 坡印廷修正，R+T+A = 1 严格成立。
  • 光子再循环：辐射复合系数按带边逃逸概率 Pesc = min(1, 1/4n²αd) 缩放，只作用于标记为吸收层的材料。
  • 自洽再吸收：未逃逸的份额在每次右端项求值时作为产生源返回，高 np 区的发射可以进入低 np 区。
  • 叠层电池只做一次 TMM，G(x) 按子电池划分，复合结层计入寄生吸收。
差异 两者能力差距最明显的一处即在光学。带金属背电极的薄膜钙钛矿电池本身就是光学腔，干涉极大相对于结的位置决定 Jsc 的量值与 EQE 的形状。SCAPS 中这部分物理只能由外部导入；SolarLab 在承载输运参数的同一套叠层上求解光学，修改光学与修改电学在构造上自动保持一致。

维度 · 后果

稳态引擎无法给出的那个测量

迟滞不是需要消除的数值伪影，它承载着离子的时间常数，是可观测量。稳态求解器只返回一条准静态曲线，即扫描速率趋于零时的极限。拖动下方的速率滑块，正反两族曲线会向该极限收拢。

维度 · 贡献

SolarLab 真正新的部分

以下六条的陈述范围有意收窄，每一条都可在源码树中核对。

01离子与载流子的时域耦合

离子作为输运物种与载流子共处同一泊松场，时间积分采用 L-稳定的隐式格式。迟滞、TPV、性能衰减与大信号阻抗出自同一套方程，无需为每种现象单独建模。

02光学在模型内计算，不从外部导入

相干传输矩阵法作用于承载输运参数的同一套叠层，光子再循环与自洽再吸收把光学回路闭合。薄膜电池本身就是一个光学腔，腔效应自动出现在 G(x) 中。

03横向维度

二维求解器采用稀疏泊松求解与二维 Scharfetter–Gummel 格式。横向均匀极限下已验证与一维结果逐位一致，随后用于一维无法表达的结构：为晶界单独指定载流子寿命，并给出 Voc 随晶粒尺寸的变化。

04单片叠层电池

一次传输矩阵计算覆盖顶电池、复合结与底电池，把光生速率分布分配给两节子电池。两节各自独立扫描，再在同一电流网格上完成电流匹配。复合结层计为寄生吸收，不作忽略。

05两个驱动，一套物理

稳态 Newton 求解器与瞬态积分器共用同一份装配好的右端项。同一个量可以按 SCAPS 的定义取无离子稳态，也可以按实验的定义取有限扫描速率下的值，不必维护两套逐渐分歧的物理模型。

06可复现性作为基础设施

器件叠层从 YAML 构建为不可变数据类（frozen dataclass）；每项物理升级都置于一个开关之后，默认路径逐位一致；回归门禁把 Voc、Jsc、FF 限定在给定区间；自动对标回路以参考数据为基准对模型评分，并记录已证伪的假设，避免重复尝试。

维度 · 校准

SCAPS 更强的方面，以及对标达到的程度

只呈现单侧优势的对比，在学位论文答辩中并不可用。SCAPS 有几处仍然更强，SolarLab 与它一致的程度也有已记录的边界。

▸缺陷物理

多价缺陷与两性缺陷，高斯分布与带尾分布，缺陷的光激发（IPV），以及占据率单独迭代的亚稳组态。SolarLab 的缺陷物理未及这一深度。

▸自适应网格

SCAPS 在迭代之间按 exp(qψ/kT) 的比值重划网格，因此能处理陡峭的带隙渐变与深能级缺陷占据。固定网格在同类问题上依赖人工指定节点数。

▸交流分析

精确的小信号线性化比解调积分波形更快，数值上也更清晰。C–V 与 C–f 分析正适合这一方法。

▸成熟度

二十年的使用积累，大量已发表参数构成的生态，曲线拟合、批处理与记录流程，以及一套脚本语言。同行阅读结果时默认以它为参照。
