稳态  ·  时域  ·  同一组半导体方程

两个引擎，同一套器件物理

面对同一个薄膜叠层，SCAPS-1D 和 SolarLab 解的是同一套方程：泊松方程与载流子连续性方程耦合成的方程组。分歧集中在三处，其余差别都由这三处派生：把哪些量当作未知量、时间算不算一个坐标、光以什么方式进入薄膜。本页把这三处选择并排摆开，逐一说清各自换来了什么。

本页是 SolarLab 求解器讲解页《求解器算的是什么》的姊妹篇。琥珀色一侧全部出自 SCAPS 手册（v3.3.03，2016 年 2 月）和 Burgelman 课题组公开发表的算法论文；青色一侧全部出自 SolarLab 源码树。

维度 · 未知量

求解器把什么当作未知量

两套程序离散的是同一组方程：一条泊松方程，加两条载流子连续性方程。分岔从因变量的选取开始：SCAPS 解准费米能级，SolarLab 解载流子浓度，而且多带一种粒子。

SCAPS-1D

(ψ, EFn, EFp)：稳态

— 泊松方程 —
−∂/∂x( ε ∂ψ/∂x ) = q( p − n + ND+ − NA− + ρdef )

— 连续性方程（∂/∂t = 0）—
∂Jn/∂x = q( Un − G )
∂Jp/∂x = −q( Up − G )

— 本构关系 —
Jn = μn n ∂EFn/∂x    Jp = μp p ∂EFp/∂x
  • 电流写成准费米能级的梯度，有效态密度项和能带偏移项已经藏在变量里面。
  • 全程玻尔兹曼统计；费米-狄拉克统计和带隙收窄都没有实现。
  • 缺陷电荷 ρdef 这一块做得很足：单价、二价到多价缺陷，两性缺陷，单能级 / 均匀 / 高斯 / 带尾分布，还有用独立占据率迭代求解的亚稳缺陷组态。
  • 时间只以独立的小信号线性化形式出现，Y = δJ/δuext = jωC + G。

SolarLab

每个节点 y = (n, p, P)：时间分辨

— 参与时间推进（线方法）—
∂n/∂t = (1/q) ∂Jn/∂x + G − R
∂p/∂t = −(1/q) ∂Jp/∂x + G − R
∂P/∂t = ∂/∂x[ DI( ∂P/∂x + (P/VT) ∂φ/∂x ) ]

— 直接求解，不作时间积分 —
−∂/∂x( ε ∂φ/∂x ) = q( p − n + P − NA + ND )
  • 状态量是载流子浓度；φ 由预先分解好的三对角方程直接解出，每次右端项求值只解一次，没有内层的泊松–牛顿迭代。
  • 第三种粒子是可动离子空位 P，在同一个电场里漂移（Nernst–Planck 形式，可选第二种离子，可选空间位阻占据上限）。
  • SG 通量把 φ+χ 和 φ+χ+Eg 分别当作电子和空穴的驱动势，SCAPS 里自带的有效态密度项在这里必须显式折进来（dos_band_potentials）；在对标器件上，这一项合计 137 mV。
  • 费米-狄拉克统计可以逐层开启，默认刻意关掉：参照程序用的是玻尔兹曼统计。
差异 纯稳态问题上，准费米能级是条件数更好的未知量，浓度型牛顿迭代停滞的那些叠层，SCAPS 照样收敛。可一旦 ∂/∂t ≠ 0，浓度就没得选：离子输运、陷阱俘获、位移电流，讲的都是某个浓度怎么随时间变。
维度 · 离散化

网格点放在哪里

两套程序都把节点堆在能带弯曲的地方。差别在于 SCAPS 是在求解过程中重新决定网格，而且把每个界面节点加倍，这一手在异质结处会实实在在地改变算出来的物理。

SCAPS-1D

自适应网格，迭代之间重新生成

  • 体内稀疏，界面和接触处加密。
  • 每个界面坐标上有两个网格点，相邻两层各占一个，界面载流子浓度因此是真正分属两侧的平面量。
  • 可以选每次迭代都重算网格：把相邻节点上 exp(qψ/kT)、exp(EFn/kT)、exp(EFp/kT)、R 和 G 的比值与 fmax = 1.60（约 12 mV）比较，据此插入节点；与 fmin = 1.05（约 1.2 mV）比较，据此删除节点。
  • 最多 7 层半导体；每个电压点最多 10 次网格重构。

SolarLab

静态的 tanh 加密多层网格

  • 逐层给定节点数，用 tanh 往每个界面加密，只建一次，整个运行都复用。
  • 每个界面只有一个节点，两层共用，能带偏移于是落在单个网格单元内，只能靠热电子发射上限对 Scharfetter–Gummel 通量作限幅来兜底。
  • 固定网格才撑得起 MaterialArrays 缓存和预分解的泊松 LU：依赖几何的计算只做一次，不必每次迭代重做。
  • 要界面平面浓度时，靠物理重构，不靠网格：用准稳态的 2×2 通量平衡（interface_plane_closure），或者在稳态牛顿迭代里显式引入界面平面态未知量。
差异 SCAPS 拿每次迭代的额外开销，换陡峭带隙渐变和多价缺陷下的稳健性。SolarLab 拿自适应性换一份缓存，这份缓存要撑过每次扫描约 105 次右端项求值；同一套几何要走上千个时间步而不是只求解几百次时，这笔账才划算。SCAPS 的网格只在界面双节点这一处多给了物理；为了补上这个差距，SolarLab 前后写过五版不同的实现。
维度 · 求解驱动

解到底是怎么求出来的

两者分歧最深的地方就在这里。SCAPS 本质是一台非线性方程组求解器，外面裹一层延拓策略；SolarLab 默认把器件当作刚性初值问题来做时间积分，后来才补上一个直接求稳态的牛顿驱动，为的就是把能跟 SCAPS 对照的量定义出来。

SCAPS-1D

Gummel 外迭代 + 方程内 Newton 子迭代

— 延拓阶梯 —
起点（EF 平直，无电势降）
  ↓  暗平衡态，0 V
  ↓  短路，1 sun，0 V
  ↓  工作点
  ↓  第一个测量点 → 扫描
  • 外层是解耦的 Gummel 循环，每个方程内部再做 Newton–Raphson 子步。
  • ψ、EFn、EFp 每次迭代的更新量限幅在 0.5 kT/q；更新量全部降到 0.001 kT 以下就算收敛；迭代上限 1000 次。
  • 相邻两级隔得太远时会自动插入中间子步，这是应对迭代发散的常规手段。
  • 可以选“过 Voc 就停”；一次扫描最多 201 个测量点。

SolarLab

线方法 + 隐式 Radau（另配一个稳态牛顿）

— 每个电压步 —
y(tk) → solve_ivp(Radau IIA，max_step 设上限)
  ↳ 失败时：把稳定时间折半细分（≤ 10 次）
  ↳ 最后手段：改用 BDF 重试
y(tk+1) 把 n、p 连同离子分布一起带到下一步

— 可选的无离子稳态（离子冻结）—
阻尼对数空间牛顿解 F(y) = 0，LU 分解复用
  • 离子–载流子–电场耦合带来的刚性，交给 Radau IIA（L 稳定，5 阶）来扛；步长之所以要设上限，是因为接近平带时雅可比矩阵接近奇异，误差估计器会低估真实误差。
  • 稳态驱动用的是同一套装配好的右端项：一套物理，两个驱动；牛顿收不下来的点交给经校验的瞬态回退计算，不会有哪一点被悄悄编出来。
  • 离子在偏置点之间的记忆不靠后处理去凑：上一步收敛的状态就是下一步的初始条件。
差异 稳态求解器回答的是器件在电压 V 下是什么表现，时域积分器回答的是电压以速率 r 变化的过程中器件是什么表现。钙钛矿恰好是这两个答案能测出差别的材料，而实验记下来的是后一个。
维度 · 边界条件

接触是怎么约束的

SCAPS-1D

金属功函数，或反解得到的平带

  • 前后接触各给多数载流子一个金属功函数 Φm；也可以选“平带”，由 SCAPS 在每个温度下反解 Φm，让能带保持平直。2014 年以后的版本换了做法，改从含深能级缺陷的总电荷中性条件反解。
  • 接触处的动力学，由电子和空穴各自的有限表面复合速度定下来，默认值惯用 107 cm/s。
  • 隧穿进出接触是可选项；每个接触还能挂一份随波长变化的反射/透射滤光片文件。
  • 外部串联电阻和并联电阻是仿真之后才加进来的，靠重新映射端电压实现，并不进入输运问题本身；量子效率的计算同样不包含这两个电阻。

SolarLab

三种接触约定可选

  • 欧姆接触的狄利克雷钉扎（默认，IonMonger 约定）：边界上的载流子浓度钉在暗态掺杂平衡值，泊松方程以配置里写定的 Vbi 为参考。
  • 罗宾 / 选择性 / 肖特基：每一侧、每种载流子各给一个有限的 Sn、Sp，J = ±q·S·(浓度 − 浓度eq)；S → ∞ 回到欧姆接触，S = 0 就是完全阻挡。
  • 平带金属接触，也就是 SCAPS 的约定：泊松边界由 compute_V_bi() 算出的功函数差驱动，不是一个写死的输入值。
  • 已记录在案的限制：平带接触配稳态牛顿是一对不兼容的组合（罗宾边界叠上陡峭的 Vbi，条件数变差，牛顿迭代会停滞）。这条按引擎边界如实记下，没有拿补丁盖过去。
差异 掺杂扫描上两套程序看着不一致，最主要的来源就是接触约定：Vbi 边界会随偏置、随掺杂摆动，它对 ETL 掺杂的响应，和 SCAPS 固定金属功函数下的响应很不一样。如今 SolarLab 两种约定都做了，正是这一步把“趋势错了”落实成有名有姓、可复现的边界条件差异。
维度 · 异质结

界面上发生了什么

两套程序的界面输运都按热电子发射算，界面复合都按 SRH 型循环算。分歧在别处：复合速率用的到底是哪一处的载流子浓度。

SCAPS-1D

界面双节点上的热电子发射

  • 界面输运按热电子发射处理，热速度 vth 取相邻两层中较小的一个。每个界面上因此都留有一小段准费米能级台阶，能带偏移为零时也不例外。
  • 界面复合走 Pauwels–Vanhoutte 理论，是 SRH 的一种推广：用一个陷阱占据率同时平衡两侧过来的俘获。
  • 半经典隧穿有四条通道：带间、带内、能带 ↔ 界面缺陷、能带 ↔ 接触。四条都只在直流下起作用，交流问题里看不见。

SolarLab

SG 通量取 TE 上限，另做平面浓度闭合

  • 只要界面上 |ΔEC| 或 |ΔEV| 超过 0.05 eV，Scharfetter–Gummel 通量就限幅到 Richardson–Dushman 热电子发射极限，免得能带偏移挤在一个网格单元里造成过量注入。
  • 界面 SRH 的 (vn, vp) 逐个界面单独给。界面在网格上只占一个共用节点，平面浓度得另外重建：要么每次右端项求值时解一个 2×2 隐式通量平衡，要么在稳态牛顿迭代里把界面平面态直接当作未知量。
  • 隧穿只留一条通道：把静态的 Padovani–Stratton 热场发射增强因子 Γ ≥ 1 折进 Richardson 常数。这一步刻意放在构建阶段做完，牛顿迭代的收缩性不受它干扰。
差异 这一节是 SCAPS 领先，记录里也照实写着：平面浓度这条路走通之前，先后试过三版基于体节点浓度的速率代数改写，对照 SCAPS 的界面趋势全部被证伪。这个教训可以复用：在这一区间里，只要速率公式取的是体节点上的浓度乘积（那里的浓度已按准费米能级自洽过），算出来的复合就完全看不到陷阱能级；只有真正的界面平面浓度才给得出这一响应。
维度 · 光学

光如何变成 G(x)

SCAPS 的内置光学模型有意做得简单：非相干比尔-朗伯吸收，反射只允许出现在接触处，内部界面不反射。吸收系数要么读文件，要么用模型 α(λ) = (A + B/hν)·√(hν − Eg)。想要更精细的光学，手册留的出口是从外部导入 g(x) 文件。SolarLab 则自己算光学，而且算的是相干光学。

SCAPS-1D

非相干，单次通过

  • 整个叠层都按比尔-朗伯吸收算，α 来自模型或文件，α(λ,y) 可以随组分渐变。
  • 反射/透射滤光片只能加在接触处；此外有中性密度滤光片、截止滤光片、从任一侧照射的选项，还带一个光谱库（AM0、AM1.5D、AM1.5G、单色光）。
  • 没有干涉，没有内部界面反射，也没有背反射层驻波。手册对此写得很明白，留给用户的变通出口是导入 g(x)。

SolarLab

相干传输矩阵法，光学闭环

  • Pettersson/Burkhard 传输矩阵覆盖整个叠层，只参与光学的衬底也算在内；带 nreal/nambient 坡印廷修正，R+T+A = 1 严格成立。
  • 光子再循环：凡是标记为吸收层的层，辐射复合系数按带边逃逸概率 Pesc = min(1, 1/4n²αd) 缩放。
  • 自洽再吸收：每次右端项求值，把没逃出去的那一份当产生源加回来；高 np 区发出的光就能喂给低 np 区。
  • 叠层电池只做一次 TMM，G(x) 直接分到各子电池，复合结层计入寄生吸收。
差异 这是本页最清楚的一处能力差距。带金属背电极的薄膜钙钛矿电池本身就是一个光学腔，干涉极大离结多远，直接决定 Jsc 和 EQE 的形状。这部分物理在 SCAPS 里只能靠导入；在 SolarLab 里，它和输运参数出自同一套叠层，改一处光学和改一处电学天然对得上。

稳态引擎给不出的那个测量

迟滞不是要消掉的数值伪影，它本身就是可观测量，离子的时间常数写在里面。稳态求解器只给一条准静态曲线，也就是扫描速率趋于零时的极限。拖动下面的扫描速率滑块，看正扫和反扫两族曲线怎么向它靠拢。

维度 · 贡献

SolarLab 真正新的部分

每一条都写得足够具体，可以逐条回源码树里核对。

01离子与载流子的全时域耦合

离子和载流子共用同一个泊松场，都当作被输运的物种一起解，用 L-稳定的隐式格式往前积分。迟滞、TPV、性能衰减、大信号阻抗都来自同一套方程，不必一个现象配一个模型。

02光学是算出来的，不是外部导入的

相干传输矩阵法直接跑在同一套带输运参数的叠层上，光子再循环与自洽再吸收把回路闭上。薄膜电池本身就是一个光学腔，这一点会直接体现在 G(x) 上，不用另外补。

03横向维度

二维求解器由稀疏泊松求解加二维 Scharfetter–Gummel 格式搭成。横向均匀的极限下，它与一维逐位一致，先过这一关，再去做一维根本写不出来的事：给晶界单独指定载流子寿命，算出 Voc 随晶粒尺寸怎么走。

04单片叠层电池

一次传输矩阵计算走完顶电池、复合结和底电池，把光生速率分布 G(x) 分给两节子电池；两节各扫各的，最后在同一套电流网格上做电流匹配。复合结那层按寄生吸收算进去，不是直接扔掉。

05两个驱动，一套物理

稳态牛顿求解器和瞬态积分器共用同一份装配好的右端项。同一个量，可以按 SCAPS 的口径定义（冻结离子的稳态），也可以按实验的口径定义（有限扫描速率），不用养两套迟早走偏的物理。

06把可复现性做成基础设施

器件叠层由 YAML 构建成不可变数据类（frozen dataclass）；每项物理升级都挂在一个开关后面，默认路径逐位一致；回归门禁把 Voc、Jsc、FF 钉在给定区间里；还有一条自动对标回路，拿参考数据给模型打分，顺手记下已被否掉的假设，同样的路不走第二遍。

维度 · 校准

SCAPS 强在哪，对标又对到什么程度

只夸一边的对比，答辩场上站不住。有几件事 SCAPS 至今做得更好；SolarLab 和它能对上到什么程度，这里也一并写清楚。

▸缺陷物理

多价缺陷与两性缺陷，高斯分布与带尾分布，缺陷的光激发（IPV），还有单独迭代占据率的亚稳组态。这一层深度，SolarLab 一点没有。

▸自适应网格

每次迭代之间按 exp(qψ/kT) 的比值重划网格。陡峭的带隙渐变、深能级缺陷占据，SCAPS 扛得住，靠的就是这一手；固定网格碰上同样的题，只能人工加减节点。

▸交流分析

精确的小信号线性化，比把积分出来的波形拿去解调更快也更干净。做 C-V 和 C-f，本来就该用它。

▸成熟度

二十年的使用积累，大量已发表参数构成的生态，曲线拟合，批处理与记录流程，外加一套脚本语言。整个领域读结果，用的就是这把尺子。
