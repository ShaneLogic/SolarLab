# P1 closure: numerical and physical validation boundary (2026-08-07)

## Decision

P1 is closed with three explicit P2 deferrals. There is no untriaged P1 item.
Closure means that each closed item satisfies its declared P1 acceptance
contract, while each deferred item remains a visible scientific limitation
with its original gates unchanged. It does not mean that every model is
externally predictive or publication-ready.

The machine-readable decision is `reproducibility/p1_gaps.yaml`:

| P1 item | Decision | Evidence boundary |
| --- | --- | --- |
| CIGS graded notch | closed | internal orientation, grid, and grading contract |
| SCAPS low-doping ETL | closed | documented contact-model numerical branch |
| Lin 2019 tandem | closed | partial external comparison with proxy inputs |
| IonMonger residual steady state | closed | frozen-ion short-circuit terminal-current mesh lane |
| c-Si QF J-V | closed | opt-in local QF model and registered grid/voltage protocol |
| c-Si transient/algebraic J-V | deferred to P2 | general compensated dynamic state is not implemented |
| c-Si external C-V parity | deferred to P2 | source geometry/deck is incompatible or unavailable |
| exact external solver curves | deferred to P2 | publication-era decks, revisions, and arrays are unavailable |

## P1 changes retained

- The c-Si production preset now requires the cancellation-safe quasi-Fermi
  J-V driver. Unsupported transient/algebraic entry points fail closed unless
  a diagnostic-only override is explicit.
- The c-Si QF lane carries pointwise residual, electron/hole continuity,
  all-face current-spread, Poisson, photon-budget, and grid-convergence
  certificates. A same-state regression isolates loss of resolvable QF
  increments in the density-Scharfetter-Gummel representation as the general
  driver failure mechanism.
- The Lin tandem stack follows the reported layer order and all reported
  thicknesses, accounts for optical-only substrate prefixes, includes all
  parasitic optical layers, and uses native Johnson-Christy Cu optical data.
- Config policy is preserved through YAML, loader, backend, frontend, and
  round-trip contracts. The frontend exposes the solver choice and blocks
  unsupported c-Si combinations without silently changing the requested
  method.
- The reproducibility registry now covers 29 configs, 19 benchmark entries,
  and 21 runtime resources with byte and semantic hashes.
- Git provenance checks are scoped to the project and bounded by a timeout.
  P0 reconstruction now passes even when loose base and target objects remain
  OneDrive placeholders: six base blobs are reverse-recovered against the
  patch's full object IDs, and three target blobs come from explicitly declared
  baseline snapshots whose SHA-256 and Git blob IDs are both verified. No P0
  frozen-file hash or patch gate is skipped or weakened.

## Quantitative closure evidence

### c-Si QF and capability boundary

The registered N=200/300/400 QF ladder certifies all 42 voltage points. At the
finest grid, Jsc is 356.842862 A/m2, Voc is 0.592684 V, FF is 0.824938, and PCE
is 17.4470 percent. The N=300-to-400 maximum pointwise current change is
0.8406 percent of fine-grid Jsc and contracts relative to the preceding pair.

On the exact same N=200, V=0, one-sun physical state, the split-QF residual is
5.822e-13, with electron/hole continuity bounds of 5.80e-10/3.51e-9 A/m2 and
all-face spread of 3.41e-10 A/m2. Collapsing that state to absolute carrier
densities gives a density-SG peak-scaled residual of 33.08 and an electron
continuity bound of 3.18 A/m2. This establishes a numerical representation
boundary; it does not establish a converged transient or algebraic c-Si J-V.

### Lin 2019 tandem

The live comparison gives Voc=2.015846 V, Jsc=145.747448 A/m2, FF=0.770529,
and PCE=22.6385 percent. The top/bottom absorbed-photon current budgets are
152.719/152.763 A/m2, and the simulated sub-cell Jsc values differ by 0.508
percent. All declared P1 gates pass without changing the 300/800 nm absorber
thicknesses or widening the pre-declared 10 percent paper windows.

This remains `partial_external_comparison`. Both absorber n,k tables are
shifted MAPbI3 proxies; several transport/contact inputs and unreported layer
thicknesses are assumptions. The proxy photon budgets are about 2.1 percent
below the champion central Jsc, so this result supports model consistency and
the declared comparison window, not parameter-free prediction.

## P0 and environment boundary

P0 frozen files, their hashes, and the acceptance gates are unchanged. The
checked-in baseline snapshots are a content-addressed recovery path, not a new
source of truth: each must match the target object ID already embedded in the
frozen patch before it can participate in reconstruction. The final verifier
reports 15 checked files, six reverse-recovered base blobs, three target
snapshots, and `reconstruction_verified=true`.

The repository's hidden `.git` directory still contains many OneDrive
placeholders and is read-only in this managed session. This can make unrelated
Git history operations time out and prevents staging or committing here. Before
release or remote submission, mark the **SolarLab repository root**, including
hidden `.git`, as Always Keep on This Device, or move/clone the repository
outside OneDrive. Deleting placeholder files under `.git/objects` would corrupt
repository history and is not an acceptable workaround. The final reproducible
gate is:

```bash
python scripts/verify_reproducibility.py --json
pytest -q tests/reproducibility/test_matrix.py
```

## P2 entry criteria

P2 starts from the three unchanged deferred contracts, in this order:

1. Implement a compensated general dynamic/mass-matrix carrier state and
   independently pass the registered c-Si N=200/300/400 transient/algebraic
   curve and point certificates.
2. Obtain a compatible external 1-D/full-area C-V deck or implement the
   published 2-D partial-contact geometry before claiming c-Si pointwise
   external parity.
3. Content-address exact publication-era IonMonger/Driftfusion revisions,
   decks, preconditioning histories, and voltage/current arrays before an
   independent curve comparison.

Until those gates pass, the current policy, partial labels, and explicit
limitations must remain in place.
